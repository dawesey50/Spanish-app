# Achievement Badge Icons — Generation Prompts

15 badge icons for the achievements system (used in Phase 27). Generate one image per prompt below.

## How to use

1. Paste a prompt into your image generator (DALL·E, Midjourney, Ideogram, etc.).
2. Generate at **1024×1024** with a **transparent background** (if the tool can't do transparency, use a plain white background and remove it with a background-removal tool).
3. Save as PNG named **exactly** as shown and drop into **`assets/achievements/`**:

| 2 | `on_a_roll.png` | On a Roll | 3-day streak |

## Rules that apply to every icon

- **No text, letters, or numbers anywhere in the image** — generators mangle them. Meaning is carried by the symbol only.
- One single centered emblem per image, inside a **circular badge** so the set looks uniform.
- Same render style for all 15 — generate them in one session if possible, and reuse the seed/style reference if your tool supports it.
- Palette (match the app): indigo `#4F46E5`, green `#059669`, amber `#D97706`, red `#DC2626`, sky blue `#0EA5E9`, gold for trophies/coins.
- Locked/greyed versions are **not needed** — the app dims the colour icon in code.
